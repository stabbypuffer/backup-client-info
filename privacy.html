Across Project Backups privacy policy

This utility is operated for its owner's personal backups. It is not a public account service.

Google data access and use

The utility requests the Google Drive drive.file permission. It uses access to application-created or explicitly authorized files to upload selected backup files, check backup metadata and integrity, download files for verification or recovery, and manage backup retention. It may inspect the signed-in account identity and available storage to confirm the intended destination and detect backup problems.

Storage and sharing

Backup content is stored locally and in the owner's selected private cloud destinations. Google Drive data used by this utility is processed for backup, verification, recovery, and destination safety. OAuth credentials are stored in private local configuration files, separately from captured backup content. The utility does not sell Google user data, use it for advertising, or intentionally publish it. Cloud storage providers process stored files under their own terms and privacy policies.

Retention and control

The owner controls selected backup content and configured retention. The owner can delete backup files from local storage and cloud destinations, subject to those providers' trash and retention behavior. Access can be revoked through Google account permissions. Revoking access stops future authorized operations; it does not automatically delete files already stored.

This website

These static pages have no application login, analytics scripts, or backup-data collection form. The website host may process ordinary request logs under its own privacy policy.

Contact
